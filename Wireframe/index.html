What is the purpose of a README file?

A README is the first file people read when they open a project. It describes what the project is for and how to set it up, which saves others time by answering common questions up front.

What is the purpose of a Wireframe?

A wireframe is a skeleton of a website or app, drawn with lines and boxes rather than colors and final content. It gives designers, developers and clients a shared plan, so changes are cheap to make before coding starts.
